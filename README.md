# 🔐 Login Responsivo

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Google Fonts](https://img.shields.io/badge/Google%20Fonts-4285F4?style=for-the-badge&logo=googlefonts&logoColor=white)

Esse é um projeto de front-end feito para criar uma tela de login responsiva, adaptada para diferentes tamanhos de tela. A ideia foi praticar Mobile First, Media Queries e estilização de formulários com HTML e CSS.

## ✨ Sobre o projeto

A página apresenta um card de login centralizado, com imagem decorativa, campos de e-mail e senha, botão de entrada e link para recuperação de senha. O layout muda conforme o tamanho da tela, ficando mais compacto no celular e mais amplo em tablets e desktops.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Media Queries
- Mobile First
- Google Material Icons
- Formulários HTML
- Imagem de fundo
- Gradiente com CSS

## 📚 O que eu pratiquei

- Criação de uma tela de login
- Estruturação de formulário com campos obrigatórios
- Uso de `autocomplete`, `required`, `minlength` e `maxlength`
- Estilização de inputs e botões
- Uso de ícones com Google Material Icons
- Layout responsivo com `@media`
- Desenvolvimento seguindo a lógica Mobile First
- Centralização de elementos com `position` e `transform`
- Transições e efeitos com `hover`

## 💡 Tipo de projeto

Esse é um projeto de estudo focado em responsividade e formulários. Ele ajudou a entender melhor como adaptar uma mesma interface para celular, tablet e desktop, mantendo o layout organizado e agradável em diferentes telas.
